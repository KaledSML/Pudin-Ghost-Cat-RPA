01 / SISTEMAS DETECTADOS

No es un gato
decorativo.

Un pequeño compañero de escritorio con una lista de actividades que el departamento de IT no ha aprobado.

SYS_01 ⌖

Seguimiento de cursor

Camina hacia el cursor y deambula por la pantalla cuando está en reposo.

SYS_02 ✣

Huellas de neón

Deja huellas pixeladas y efectos visuales mientras explora tu escritorio.

SYS_03 ◷

Modo Pomodoro

Alterna sesiones de enfoque de 25 minutos con descansos de 5 minutos.

SYS_04 ♫

Detector de música

Puede ponerse a bailar cuando el título de la ventana activa menciona YouTube o Spotify.

SYS_05 ⚡

Travesuras RPA

Algunas bromas minimizan o sacuden ventanas, o abren el Bloc de notas para escribir mensajes.

SYS_06 ♡

Protocolo del snack

Deja un saquito de comida. Pudin irá a comer y se tomará un descanso de sus travesuras.

02 / MANUAL DE SUPERVIVENCIA

Controla el caos.

Aprende los comandos esenciales antes de liberar al felino en tu sistema.

pudin://input-map
P

Pausar o reanudar a Pudin.

F

Dejar un saquito de comida.

CLIC DERECHO

También deja comida cerca del gato.

CLIC IZQ.

Arrastrar a Pudin por el escritorio. Si lo sujetas demasiado, puede activar su modo troll.

ESC

Cerrar la aplicación.

⚠ AVISO DEL SISTEMA

Este gato tiene permisos.

Pudin puede interactuar con ventanas de Windows y cambiar el fondo de pantalla. Sus travesuras pueden interrumpir tu trabajo.

Importante: el fondo de pantalla original no se restaura automáticamente. Ejecuta el proyecto solo si entiendes y aceptas estos comportamientos.

03 / PROTOCOLO DE INVOCACIÓN

Boot Pudin.exe

Clona el repositorio, instala las dependencias y lanza el programa desde su carpeta.

TERMINAL // POWERSHELL O CMD PYTHON 
# 1. Clonar el repositorio
git clone https://github.com/KaledSML/Pudin-Ghost-Cat-RPA.git

# 2. Entrar al proyecto e instalar dependencias
cd Pudin-Ghost-Cat-RPA
pip install -r requirements.txt

# 3. Ejecutar Pudin
cd pudin_cat
python main.py
