02 // HUMAN INTERFACE

CONTROLA AL GATO.
BUENA SUERTE.

Puedes intentar dirigir sus acciones. Pudin se reserva el derecho de juzgar tus decisiones.

input_configuration.exe READY
P

Pausar / reanudar
Detiene o reanuda las travesuras automáticas.

F / RMB

Ofrecer un sachet
Coloca un snack cerca del cursor. Si Pudin se lo come, no hará travesuras durante dos minutos.

LMB + DRAG

Agarrar y mover
Puedes arrastrarlo. Si lo mantienes agarrado más de dos segundos, puede enfadarse y tomar el control del cursor durante unos segundos.

ESC

Cerrar Pudin
Termina la sesión del pequeño fantasma.

⚠ HUMAN WARNING

Tu escritorio es su territorio.

Pudin puede minimizar o sacudir ventanas, escribir automáticamente en el Bloc de notas y cambiar el fondo de pantalla.

Importante: el fondo de pantalla no se restaura automáticamente al cerrar la aplicación. Guarda el original y guarda tu trabajo antes de invocarlo.

03 // SUMMONING RITUAL

INSTALA EL CAOS.
EN TRES, DOS, MIAU.

Necesitas Windows, Python 3 y la disposición de aceptar que tu escritorio ya no te pertenece del todo.

STEP 01

Clona el repositorio

Descarga los archivos de Pudin desde GitHub.

STEP 02

Instala las dependencias

Deja que Python prepare el entorno.

STEP 03

Invoca al fantasma

Ejecuta el programa y conoce a tu nuevo compañero.

Explorar repositorio en GitHub ↗

summon_pudin.exe 
git clone https://github.com/KaledSML/Pudin-Ghost-Cat-RPA.git
cd Pudin-Ghost-Cat-RPA
pip install -r requirements.txt
cd pudin_cat
python main.py

✦ Ejecuta los comandos desde una terminal. Asegúrate de tener Python 3 instalado y disponible en el PATH.
