Adóptalo

git clone https://github.com/KaledSML/Pudin-Ghost-Cat-RPA.git
cd Pudin-Ghost-Cat-RPA/pudin_cat
pip install -r ../requirements.txt
python main.py

Solo para Windows, con Python 3.

Ojo: Pudin cambia tu fondo de pantalla y no lo devuelve. Guarda el tuyo antes de abrirlo.
